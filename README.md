## 🛠️ Tech Stack & Scripts

- **Framework**: React 19 + TypeScript (Strict with `verbatimModuleSyntax`)
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Micro-interactions**: Canvas Confetti
- **Storage**: LocalStorage automatic sync with demo reset

```bash
# Run locally
npm install
npm run dev

# Production build
npm run build
```
